# 独立二维码展示页

地址：**`http://<node-address>:31082/`**，其中 `<node-address>` 是客户端可访问的 Kubernetes 节点地址。

1. 使用工作台账号登录；同一浏览器、同一主机已登录工作台时会共用会话。
2. 下拉选择 PostgreSQL 台账中的料筐，自动显示对应 QR Code。内容就是料筐编号，与工作台的二维码标签相同。
3. 可点「全屏展示」，让真实 IP 摄像头对准屏幕。按 Esc 退出全屏。
4. 点「清空画面」移除二维码；台账有改动时点「刷新列表」。

真摄像头 RTSP 地址仍在工作台「设置」中配置。二维码页面只展示标签。摄像头持续识别，稳定识别即视为入口到位并启动 MES 校验，不需要手动设置入口传感器；已占用、停用或质检未通过的料筐可以展示，但不会因此获得入炉资格。

`qr-display` 为独立静态编译的 Go 进程，提供 Vue 静态页面并代理现有的登录、会话、料筐列表和 QR 图片 API。数据库由 core 读取；这个服务不持有数据库连接，也不代理设备控制或内部 API。

随正常 `build.sh` 构建、`up.sh` 启动、`stop.sh` 停止。单独更新页面：

```sh
sh scripts/build.sh qr-display
sh scripts/up.sh
```

页面与后端 QR 接口可在本机验证；真实摄像头对屏识别仍需接入摄像头后验证。
